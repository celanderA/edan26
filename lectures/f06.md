## Atomic objects

- Atomic object were introduced in C11
- Atomic objects can safely be accessed without locking
  \_Atomic int counter = 0;
  Thread 1 Thread 2
  counter++; counter++;
- Of cource you my need locks for other reasons to portect your data
- Atomic objects have a global modification order and all thread see the same modification order.
- There is no total modification order of all atomic object s-- different threads can see the stores to different atomic objects in different orders.
